# Bangkok Michelin Street Food

A static one-page guide for Bangkok street food, combining MICHELIN-listed spots and 肥波外食記 recommendations with a revisit ranking and quick decision guide.

## GitHub Pages

This repo is designed to be served directly from GitHub Pages.

Recommended Pages setting:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

Main entry point: `index.html`
